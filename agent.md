# Генерация текстур жидкостей

Текстуры жидкостей генерируются программно на Python (PIL + numpy) без какой-либо
генеративной модели изображений. Это не «нарисованная ИИ картинка», а чисто
математически построенный узор.

## Базовый алгоритм

**Still (статичная жидкость).** Берётся базовый цвет, поверх него накладывается
синусоидальная рябь:

```python
wave = sin(x/16 * 2π * freq + y*0.5) + sin(y/16 * 2π * freq*0.7 + x*0.3)
shade = wave * ripple_strength
```

Две наложенные синусоиды по разным осям дают неровный, органичный узор вместо
плоской заливки. Сверху добавляется немного случайного шума на каждый пиксель,
чтобы не прослеживалась математическая правильность.

**Flow (текущая жидкость).** Та же идея, но волна идёт по диагонали `(x+y)`,
что создаёт направленные полосы вместо ряби — читается как «течёт», а не «стоит».

## Модификаторы поверх базового узора

Под конкретный смысл жидкости добавляются дополнительные функции:

- `add_bubbles` — для газов (пропан, бутан): несколько случайных светлых кругов
  с мягким затуханием к краям — имитация пузырьков/просветов в газе.
- `add_blotches` — для «грязных»/нечистых жидкостей (кустарный бензин, Wet Gas,
  смесь нитроалканов): тёмные или цветные пятна неправильной формы с затуханием —
  визуально сигнализируют «неочищенный продукт».
- `add_sparkle` — для нитрометана: единичные яркие пиксели-блики для ощущения
  «экзотической химии».

## Выбор цвета

Цвет задаётся не случайно, а исходя из реальной химии/физики продукта:

- лёгкие фракции (нафта, пропан) — светлые и прозрачные (низкий alpha);
- тяжёлые (мазут, гудрон) — тёмные и почти непрозрачные (высокий alpha);
- топливные тиры внутри одной линейки (низкий/средний/высокий) — один и тот же
  оттенок, но с ростом «чистоты»: меньше шума, выше насыщенность. Без случайных
  скачков цвета, чтобы визуально читалось родство продуктов.

## Технические детали под Minecraft

- Текстура генерируется сразу в 16×16 (нативный размер текстуры жидкости).
- Именование: `<название>_still.png` (статичная) и `<название>_flow.png` (текущая)
  в папке `textures/neoforge/assets/harderdiesel/textures/block/`.

# Заметки по дизайну — Create: Harder Diesel

## Типы сырой нефти

Разные биомы дают разную сырую нефть. «Sweet» = без серы, «Sour» = с серой
(выдаёт Molten Sulfur при дистилляции). Профиль выхода — примерный, на 100 mb
сырья, склон в сторону лёгких (Naphtha/Kerosene) или тяжёлых (Mazut) фракций.

| Сорт (registry id) | Биом спавна | Naphtha | Kerosene | Mazut | Molten Sulfur |
|---|---|---|---|---|---|
| `light_sweet_crude` | Пустыня | высоко | высоко | мало | нет |
| `light_sour_crude` | Бэдлендс | высоко | высоко | мало | мало |
| `medium_sweet_crude` | Равнины/лес | средне | средне | средне | нет |
| `medium_sour_crude` | Болото | средне | средне | средне | средне |
| `heavy_sweet_crude` | Тайга/тундра | мало | средне | много | нет |
| `heavy_sour_crude` | Океан | мало | средне | много | больше всего |

Molten Sulfur (`molten_sulfur`) — побочный продукт Sour-нефти; Heavy Sour даёт его
больше всего, Light Sour — меньше всего. Сейчас добавлены только сами жидкости;
рецепты дистилляции и биомовый спавн — отдельная задача.

## Архитектура машин

- **Separator** — разделение готовых смесей на чистые компоненты
  (Wet Gas → Propane + Butane, Mixed Nitroalkanes → нитро-тройка). Пока нет в моде.
- **Cracker** — всё, что ломает молекулы (коксование мазута, крекинг керосина,
  потенциальный FCC). В разработке.

## Подтверждённая цепочка тиров

| Тир | Жидкости | Роль |
|-----|----------|------|
| 0 — Био | Vegetable Oil, Ethanol, Biodiesel | Присадки/топливо, база под нитроглицерин |
| 1 — Первичка | Naphtha, Kerosene, Mazut, Wet Gas | Сырьё |
| 1 — Топливо | Low-Octane Gasoline, Low-Cetane Diesel | Базовое топливо |
| Газы | Propane/Butane/LPG (газ + сжиженный) | Сырьё для нитрования/алкилирования, товарный LPG |
| 2 | Tar/Гудрон, Medium-Cetane Diesel | Утилити / топливо (требует H2, мод createbb) |
| 3 — Легально | High-Octane Gasoline (+этанол), Premium Diesel (+нитроэтан/пропан) | Топливо высшего легального качества |
| 3 — Нелегально | Кустарный высокооктановый бензин (+нитрометан) | Обходной путь |
| 4 — Нитро | Mixed Nitroalkanes → Nitromethane/Nitroethane/Nitropropane | Эндгейм-топливо + компоненты дизеля |

## Задача

Нелегальное топливо (кустарный высокооктановый бензин) должно быть хуже легального
высокооктанового, но не слишком.

## Взрывчатка (концепт)

- Vegetable Oil → Biodiesel + Glycerol
- Glycerol + Nitric Acid → Nitroglycerin (взрывоопасен при тряске/перегреве)
- Nitroglycerin + стабилизатор → Dynamite

Пока только концепт, без текстур/цифр.

## Внешние зависимости

- Nitric Acid — мод Power Grid
- Hydrogen — мод Create Broken Bad (createbb)

## Нерешённые/предложенные ветки

- **FCC**: VGO → Cracked Naphtha + Light Cycle Oil + FCC Gas — обсуждалось, не подтверждено.
- **Алкилирование бутана**: Butane + FCC Gas → Alkylate — зависит от FCC.
- **Ароматика**: риформинг нафты → Reformate → Benzene/Toluene/Xylene;
  Toluene → TNT — под вопросом сам путь, риформинга в бензиновой цепочке нет.
- **Расширение керосина**:
  - A: гидрокрекинг керосина (+H2) → Naphtha + Low-Cetane Diesel;
  - B: деасфальтизация Vacuum Residue керосином → Deasphalted Oil (закрывает VGO-хвост);
  - C: очистка в Clean Kerosene/Jet Fuel (задел под авиацию);
  - D: керосин как зимняя присадка к дизелю.
