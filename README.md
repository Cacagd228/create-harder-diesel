# Create: Harder Diesel

Реалистичная нефтепереработка для Create. Мод добавляет собственную цепочку
переработки нефти: сорта сырья по биомам, посортовую перегонку, гидроочистку,
крекинг, ароматическую ветку — и топливную лестницу от гудрона до авиатоплива.

> Для NeoForge 1.21.1, расширяет мод **Create Diesel Generators (CDG)**.

---

## Возможности

- **Сорта сырой нефти** — «сладкие» (без серы) и «кислые» (сернистые),
  лёгкие/средние/тяжёлые. В мире генерируются 4 сорта: тяжёлые преобладают
  в болотах и океанах, средние и сладкие — в пустынях и бэдлендах;
  лёгкие сорта добываются механиками других модов.
- **Редкость месторождений**: доля чанков с нефтью настраивается
  (`OilChunkChance`, по умолчанию 50%), детерминирована от seed мира.
- **Нефть можно выключить**: `/harderdiesel oil disable` — добыча
  останавливается, сканер сообщает о «неведомой силе», а существующие
  месторождения сохраняются и возобновляют работу после `enable`.
- **Собственные мультиблочные машины** на базе баков: крекинг-реактор
  и сепаратор.
- **Сернистые фракции** — кислая нефть даёт сернистую нафту и сернистый
  керосин, которые нужно очищать гидроочисткой (водород) с выходом серы.
- **Ароматическая ветка** — риформинг крекинг-нафты даёт риформат и BTX:
  альтернативные рецепты бензина и дизеля без этанола, нитрометана и водорода.
- **Алкилат** — премиальное бензиновое топливо из продуктов крекинга.
- **Загрязнение** — машины выбрасывают смог (настраивается), он
  распространяется по чанкам независимо от их загрузки, накладывает дебафы
  по тирам T1–T5 и отображается на карте Xaero's.
- **12 генераторов** — 4 семейства топлива (бензин / дизель / газ / нитро)
  × 3 размера, плюс тяга для дирижаблей (Create Aeronautics).

## Цепочка переработки

```
Сырая нефть (сорта по биомам)
  └─ Перегонка (колонна CDG; нагрев / сверхнагрев)
       ├─ Нафта / Сернистая нафта ── очистка (+H₂) → Нафта + Сера
       ├─ Керосин / Сернистый керосин ── очистка (+H₂) → Керосин + Сера
       ├─ Тяжёлый газойль → Мазут → Гудрон
       │                      └→ FCC → Крекинг-нафта + LCO + FCC-газ
       │                            Крекинг-нафта → Риформинг → Риформат → BTX
       └─ Нефтяной газ → Сепаратор → Пропан + Бутан

Нафта      → Низкоокт. бензин + Низкоцет. дизель
Бензин:    LOG + этанол → HOG          LOG + риформат 40% → HOG
           LOG + нитрометан → артиc.   LOG + толуол 20%   → артиc.
Дизель:    LCD + водород → MCD         LCD + ксилол 15%   → MCD
           MCD + LCO/нитропропан/нитроэтан → HCD
Керосин    + нитроэтан → Авиатопливо (лёгкая вершина: мало СУ и расхода)
Вакуумный остаток → Крекинг-реактор → ВГО + Гудрон
FCC-газ + серная кислота → Алкилат
```

## Топлива (энергоёмкость, множитель от гудрона)

| × | Топливо |
|---|---|
| 1 | Гудрон |
| 2.5–3 | Нефтяной газ, FCC-газ |
| 4–5 | Низкоокт. бензин, низкоцет. дизель, керосин |
| 6–7 | Пропан/бутан, среднецет. дизель, смесь нитроалканов, LPG |
| ~8 | Высокоокт. бензин, алкилат, нитропропан |
| 8.3–8.5 | Артиc. бензин, нитроэтан |
| 10 | Высокоцетановый дизель |
| 12 | Нитрометан |
| 14.4 | Авиатопливо |

## Машины

| Машина | Назначение | Тепло |
|---|---|---|
| Ректификационная колонна (CDG) | Перегонка сырья и фракций | нагрев / сверхнагрев |
| Крекинг-реактор | Вак. остаток → ВГО + гудрон; LPG → олефины | сверхнагрев |
| Сепаратор | Разделение смесей на 2–7 выходов | не требуется |
| Механический миксер (Create) | Смешивание и гидроочистка | по рецепту |

> ⚠️ Крафты машин и контроллеров пока в разработке — в выживании
> недоступны, получайте через креатив.

## Баки-мультиблоки

| Бак | Ёмкость |
|---|---|
| Гальванический реакционный бак | базовая |
| Износостойкий бак | базовая |
| Сверхстойкий платиновый бак | **×2** |

Служат основой реакторов: выставляется столбик баком нужной высоты,
затем контроллер превращает его в машину. Окна переключаются гаечным ключом.

## Загрязнение

- Эмиссия настраивается отдельно для колонны, крекинга и сепаратора
  (`POLLUTION_*_EMIT`), глобальный множитель — командой или конфигом.
- Смог диффундирует между чанками и распадается со временем даже там,
  где никто не играет; накопление — только в загруженных чанках.
- Дебафы по тирам T1–T5: тошнота → отравление → голод → иссушение.
- **Анализатор воздуха** — ПКМ запускает сканирование с прогресс-баром,
  показывает загрязнение чанка и тир.
- Команды `/harderdiesel`:
  - `pollution multiplier <x>` · `decay <v>` · `diffusion <v>`
  - `pollution get [chunkX chunkZ]` · `set <x> <z> <v>`
  - `oil enable | disable | status`

Интеграция с картой — при наличии **XaerosZones** (опционально).

## Зависимости

- **NeoForge** (обязательно)
- **Create** (обязательно)
- **Create Diesel Generators** (обязательно)

Опциональные моды, добавляющие рецепты:

- **Create Broken Bad** — водород для гидроочистки и среднецетанового дизеля
- **Power Grid** — серная кислота для смеси нитроалканов
- **XaerosZones** — слой загрязнения на картах Xaero's

## Сборка

```bash
gradlew build
```

Готовый jar: `build/libs/harderdiesel-<версия>.jar`.
Для dev-окружения нужны локальные jar в `libs/` (powergrid, xaeroszones,
flywheel, Registrate и др.).
